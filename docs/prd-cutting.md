# 합판 재단 프로그램 PRD (확정)

- 확정일: 2026-10-30 (사장님 확정)
- 우선순위: 0번, 견적서·도면보다 먼저
- 전체 PRD: https://claude.ai/artifact/XhKignhGZh2xCpGxH6jaZ2

## 왜 만드나

지금은 "견적서" 구글 시트의 입력·요약·설정 탭 수식으로 합판 장수를 구한다. 같은 크기 부품만 있을 때는 맞지만, 크기가 섞이면 한 장에 여러 부품을 섞어 넣지 못해서 장수가 많게 나온다. 상용 재단 프로그램은 1년에 약 2,000만 원이라, 직접 만들어 그 비용을 아낀다.

지금 수식의 문제 (2026-10-30 확인):

- 요약 탭 "필요한 장수"가 0으로 나온다. 회전허용이 Y면 "돌린 배치"와 "그대로 배치" 중 작은 값을 고르는데, 돌리면 판에 안 들어가는 부품(예: 700×2300)은 0이 되고 그 0이 뽑힌다.
- 입력 탭의 빈 줄은 "1장당 배치수"가 323,607로 나온다. 수량이 0이라 결과에는 영향이 없다.

## 기준값

| 항목 | 값 |
|---|---|
| 합판 크기 | 1220 × 2440 (모든 자재 같음), 면적 2,976,800㎟ |
| 톱날 두께 | 3mm |
| 가장자리 여백 | 10mm, 네 변 모두 |
| 실제로 쓸 수 있는 면 | 1200 × 2420 |
| 입력 치수 | 엣지 붙이기 전 재단 치수 |

## 확인용 예시

| 예시 | 면적으로 나눈 값 | 부품별로 따로 셈 | 정답 |
|---|---|---|---|
| 700×2300 20개 | 11장 | 20장 | **20장** |
| 서랍장: 700×2000 4개 + 450×2000 4개 | 4장 | 6장 | **4장** |

- 700×2300: 700 두 개를 나란히 놓으면 1403mm가 필요해서 한 장에 하나만 들어간다. 장마다 약 497×2420 띠가 남는다.
- 서랍장: 700짜리와 450짜리를 한 장에 나란히 놓으면 1153mm로 들어간다. 장마다 1200×417 띠가 남는다. (문짝 2짝 크기는 사장님이 나중에 알려줌)

## 만들 기능

1. **입력**
   - 부품 이름, 가로, 세로, 수량, 자재(합판 종류·색상·두께)를 넣는다.
   - 결 있는 자재를 고르면 계산 전에 "어느 부품이 결을 따라야 하나요?"를 먼저 묻는다. 결을 따라야 하는 부품은 돌리지 않는다.
2. **계산**
   - 자재별로 따로 계산한다 (한 장 단가가 자재마다 다르다).
   - 판넬쏘처럼 끝에서 끝까지 일자로 자르는 방식(길로틴 재단)으로 배치한다.
   - 톱날 3mm와 여백 10mm를 빼고, 큰 부품부터 넣은 뒤 남는 띠에 작은 부품을 채운다. 여러 순서로 시도해서 장수가 가장 적은 배치를 고른다.
   - 1220 방향으로 먼저 켜는 경우와 2440 방향으로 먼저 켜는 경우를 둘 다 계산해서 더 적게 드는 쪽을 고른다.
   - 재사용 목록에 있는 자투리를 새 합판보다 먼저 쓴다.
3. **결과**
   - 자재별 필요 장수와 자재비 (합판 탭의 한 장 단가로 계산)
   - 장마다 배치 그림 (부품 이름과 치수 표시)과 사용률(%)
   - 자투리 목록: 재단하고 남은 부위를 크기와 함께 전부 보여준다. 사장님이 "재사용"이나 "폐기"를 고르면, 재사용한 것만 목록에 남는다.
4. **재단 순서** ("재단 프로그램에는 다음과 같은 순서로 입력하시오")
   - 재단기: 서광기계 CNC-3500. 화면에서 순서 1~8마다 "입력치수, 횟수"를 손으로 넣는다 (파일 입력 없음).
   - 장마다 투입 방향(1220 / 2440)을 알려주고, 화면과 같은 "순서 · 입력치수 · 횟수" 표로 보여준다. 한 번에 8줄씩 보여준다.
   - 입력치수는 부품 크기 그대로 넣는다 (톱날을 더하지 않음).
5. **연결 (다음 단계)**
   - 필요 장수와 자재비를 견적서에 넘긴다.
   - 스케치업 도면에서 부품 목록을 바로 받아온다.

## 쓰는 환경

- 사무실 PC(윈도우)가 서버. 엑셀과 스케치업 2026이 설치돼 있다.
- 현장에서는 휴대폰이나 12인치 패드로 접속한다.

## 완료 기준

- 위 두 예시처럼 손으로 확인한 답과 같은 장수가 나온다.
- 최근 현장 몇 건을 넣었을 때 실제 발주한 장수보다 같거나 적다.
- 배치 그림과 재단 순서대로 CNC-3500에서 실제로 자를 수 있다 (사장님 확인).
- 몇 초 안에 계산되고, 사용료가 들지 않는다.
