# 재단 결과 → 견적서 연결 PRD

- 작성일: 2026-10-30 (사장님 답변 반영, "진행" 승인)
- 앞 단계: [합판 재단 프로그램 PRD](prd-cutting.md)

- 견적서: 구글 시트 "견적서" (https://docs.google.com/spreadsheets/d/18E6PoFA2wp8scGi2ekhfsrJOrhyEMXfzLiqv6kHlRUs)

## 왜 하나

재단 프로그램이 자재별로 필요한 합판 장수를 정확히 낸다. 그런데 견적서 시트의 견적 탭에는 시공비·하드웨어·EP·대리석 칸만 있고 합판(몸통·문짝) 금액 칸이 없다. 재단 결과의 합판 금액을 견적서까지 이어 준다.

## 정한 것 (2026-10-30 사장님)

| 항목 | 결정 |
|---|---|
| 합판 금액 | **자재별 장수 × 한 장 단가** (배수 없음) |
| 단가 | 견적서 시트 "합판" 탭 단가를 처음 값으로 넣고, 사장님이 화면에서 직접 고칠 수 있다. 고친 값은 다음 현장에도 남는다. |
| 엣지값 | 사장님이 현장마다 자재별로 직접 금액을 넣는다. |
| 견적서로 보내기 | 1단계: "복사" 버튼 → 견적서 시트에 붙여넣기. 2단계(나중): Apps Script로 자동 저장. |

## 만들 기능

1. **자재 단가**
   - 합판 탭의 PB15 / PB18 / PB단면 / MD18 색상별 단가를 자재 목록에 넣는다. 이름은 "종류 + 색상" (예: "PB18 2114", "MD18 실키클라우드 무광").
   - 부품 표의 자재 칸에서 이 목록을 고를 수 있다.
   - 3번 "자재 확인" 표에서 한 장 단가를 고칠 수 있다.
2. **결과의 "견적서로 보내기" 칸**
   - 자재마다: 장수, 한 장 단가, 합판 금액(장수 × 단가), 엣지값(직접 입력), 합계.
   - 맨 아래 현장 합계.
   - "모두 한 자재로 (테스트)"로 계산했으면 금액이 맞지 않으니 "자재별로 따로"로 다시 계산하라고 알려 준다.
   - 단가가 비어 있는 자재는 0원으로 세고 표시해 준다.
3. **복사 → 붙여넣기**
   - "견적서로 복사" 버튼을 누르면 표가 복사된다 (현장, 날짜, 자재, 장수, 단가, 합판 금액, 엣지, 합계).
   - 견적서 시트의 "합판재단" 탭에 붙여넣는다. 견적 탭에는 "합판" 칸을 하나 만들어 합판재단 탭의 합계를 더한다 (처음 한 번만 사장님이 설정, 방법은 화면에 안내).
   - 복사가 막힌 기기에서는 표를 글자로 보여 줘서 손으로 복사할 수 있게 한다.

## 완료 기준

- 자재별로 따로 계산한 결과에서 합판 금액 = 장수 × 단가가 맞게 나온다.
- 단가와 엣지값을 고치면 금액이 바로 바뀌고, 단가는 다시 열어도 남아 있다.
- 복사해서 구글 시트에 붙이면 칸이 맞게 들어간다.
