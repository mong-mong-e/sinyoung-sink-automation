# 도면 라이브러리 자동 정리

`drawing_library.gs`는 구글 드라이브 "도면" 폴더의 현장 폴더들을 돌면서 PNG·JPG·SKP 파일을
"도면 라이브러리" 폴더 안의 종류별 폴더로 **복사**합니다. 원본은 그대로 둡니다.

- 분류 폴더: 싱크 / 붙박이장 / 상판·대리석 / 수납장·기타장 / 견적서 캡처 / 미분류
- 복사본 이름: `26-10-26 해파랑컴퍼니_명지국제8로 258 - 싱크.png` (날짜 + 현장 + 원래 이름)
- SKP는 같은 폴더 그림들의 분류를 따라갑니다. SKB(자동 백업본)는 기본으로 뺍니다.
- 무엇을 어디로 복사했는지는 라이브러리 안 "도면 라이브러리 목록" 시트에 남습니다.
- 한 번 복사한 파일은 다시 복사하지 않습니다. 매주 월요일 새벽 6시에 새 파일만 복사합니다.

## 처음 한 번 설치 (5분)

1. 도면 폴더에 편집 권한이 있는 구글 계정으로 https://script.google.com 에 들어갑니다.
2. "새 프로젝트"를 누르고, 기본 코드를 지운 뒤 `drawing_library.gs` 내용을 붙여 넣습니다.
3. 프로젝트 이름을 "도면 라이브러리"로 바꾸고 저장합니다.
4. 위쪽 함수 선택에서 `setup`을 고르고 "실행"을 누릅니다.
5. 권한 요청이 뜨면 계정을 고르고 "고급 → 안전하지 않은 페이지로 이동 → 허용"을 누릅니다.
   (내가 만든 스크립트라서 구글이 확인하지 않았다는 경고가 뜨는 것입니다.)

첫 실행은 파일이 많아서 5분 단위로 나눠 몇 번 이어서 돕니다. 따로 할 일은 없습니다.

## 분류 고치기

`미분류`로 간 파일은 드라이브에서 맞는 폴더로 옮기면 됩니다. 이름 규칙을 바꾸려면
스크립트 위쪽 `RULES`의 단어 목록을 고칩니다.
